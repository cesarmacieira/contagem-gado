# Deploy Streamlit

Repositorio: cesarmacieira-cast/contagem-gado
Branch: main
Arquivo de entrada: streamlit_app.py
Python: 3.12

Os pesos estao em Git LFS. Clone com git lfs pull se baixar localmente. A hospedagem precisa materializar os arquivos LFS antes de iniciar.

Em Secrets, configure OPENAI_API_KEY e CONTAGEM_VLM_ACCESS_CODE (codigo privado de acesso ao uso da chave do servidor). Sem o codigo, visitantes so usam VLM com chave propria. Nunca coloque chaves no Git. A deteccao local funciona sem API.

Limites: video mede animais simultaneos, nao individuos unicos; rebanho denso experimental; proposta de 7 na foto Nelore continua incerta.
